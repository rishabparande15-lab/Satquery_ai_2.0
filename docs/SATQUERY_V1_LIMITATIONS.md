# SatQuery v1 limitations

SatQuery v1 demonstrates a functioning paired S1+S2 VLM architecture using
official CROMA joint features and a verified joint projector. It is technically
validated and reproducible. However, the bounded fixed panel did not establish
clear improvement over S2-only; S2-only performed better for Binary and MCQ,
and generated decisions showed weak modality-identity sensitivity.

No claim is made of SOTA performance, benchmark superiority, generalization,
or fusion-driven accuracy improvement. TEST data remained untouched.
