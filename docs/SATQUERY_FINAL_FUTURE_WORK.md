# SatQuery future work

These are proposals, not current capabilities.

1. Run authorized VRSBench and RSVQA evaluation with split-safe procedures and official metrics.
2. Integrate a validated grounding specialist with trustworthy image-to-coordinate mapping.
3. Add spatial change masks only when a model and ground-truth evaluation support them.
4. Add calibrated uncertainty after a dedicated validation protocol.
5. Investigate optical-SAR fusion only if controlled experiments demonstrate a reproducible improvement.
6. Validate Cartosat-2S and RISAT adapters with authorized sensor-specific data before enabling those inputs.
7. Resolve the separate CDVQA provenance track only after authoritative image linkage, chronology, usage terms, and split-safe acquisition are available.
8. Add further specialists only when their input contracts, evaluation evidence, and warning policies are documented.
